# 本地数据保存、刷新、备份、恢复与清空

## 快速结论

项目、任务、专注记录、界面偏好和专注方案主要保存在**当前浏览器的当前设备**。普通刷新后通常仍在，但这不是账号云同步：换浏览器、换设备、清理站点数据或使用隐私模式都可能看不到原数据。

## 前置条件

- 已进入“番茄智舱”的“数据概览”页面。
- 浏览器允许下载和选择本地文件。

## 导出备份

1. 点击页面顶部的“导出备份”。
2. 等待浏览器下载名称类似 `tomato-study-room-日期.json` 的文件。
3. 将备份文件保存到可信且不容易被清理的位置。

## 恢复备份

1. 点击页面顶部带文件上传图标的“导入新版备份”。
2. 选择由当前版本导出的完整 JSON 备份包。
3. 等待页面显示“备份已恢复”。
4. 检查项目、记录、偏好和自定义媒体是否符合预期。

## 清空全部本地数据

1. 必要时先导出备份。
2. 点击“清空全部数据”。
3. 阅读确认提示，再确认清空。

## 预期结果

- 导出文件包含项目、任务、专注记录、主题偏好、番茄方案和自定义媒体。
- 导入成功后，当前浏览器中的相应数据被备份内容替换。
- 清空后，项目、任务、记录、偏好、自定义音频和相关离线缓存被移除。

## 失败处理

1. 若刷新后数据消失，确认是否换了浏览器、域名、端口、设备或浏览器用户配置。
2. 若导入失败，确认文件由当前版本导出，且没有被手工修改或截断。
3. 若浏览器存储空间不足，删除不再需要的自定义媒体后重试，并及时导出备份。
4. 清空全部数据不可撤销；没有备份时，当前功能无法恢复已清除内容。

## 隐私与同步边界

- 当前资料不能证明项目数据会自动上传或跨设备同步。
- 客服不得承诺清理浏览器数据后仍能恢复，也不得要求用户提供完整备份文件中的私人任务内容。
