## 使用边界

1. 开源项目用于展示可选工具和实现方式，不是番茄工作法有效性的学术证据。
2. GitHub 项目的功能、维护状态、许可证和下载安全性可能变化，回答时应提醒用户在项目主页重新核对。
3. 不应根据星标数量把某个工具称为“最好”或“最权威”。
4. 返回来源时优先给出与当前回答直接相关的 1 至 3 个标题和链接，不要机械列出全部来源。
5. 无法打开某个二级来源时，可以说明暂时无法核验，不得根据搜索摘要补写具体结论。
