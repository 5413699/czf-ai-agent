# 开始、暂停、继续和结束一轮番茄专注

## 快速理解

番茄钟像一条自动运行的接力赛道：专注结束后进入休息，休息结束后再回到下一轮专注。用户只需要选好节奏和目标，再按一次开始。

## 前置条件

- 已进入“专注”页面。
- 浏览器允许页面正常运行 JavaScript。
- 如需把成果累计到任务，需先在“任务”页面创建项目或任务。

## 操作步骤

1. 在“本次节奏”中选择一个方案，例如“经典番茄”。
2. 在任务选择框中选择项目、任务或子任务；也可以保留为自由专注。
3. 在目标输入框中写下一句本轮目标，例如“完成登录接口的参数校验”。
4. 点击“开始专注”。
5. 临时中断时点击“暂停一下”，恢复时点击“继续专注”。
6. 如需重新开始当前阶段，点击带回转箭头的“重置”按钮。
7. 如需直接进入下一阶段，点击“跳过当前阶段”按钮。

## 预期结果

- 倒计时开始递减，按钮变为“暂停一下”。
- 完整完成专注阶段后会生成一条专注记录。
- 已关联任务或子任务时，完成的番茄会累计到对应进度。

## 失败处理

1. 若按钮可以点击但倒计时不动，刷新页面并重新开始。
2. 若网页被浏览器限制存储，计时仍可能运行，但刷新后的恢复结果无法保证。
3. 若提示音或背景音没有播放，先在页面内再次点击开始；浏览器通常要求用户主动交互后才允许播放声音。
4. 若任务列表为空，先进入“任务”页面创建项目和任务，或直接使用自由专注。

## 重要边界

- “重置”和“跳过当前阶段”不等同于完整完成一轮专注，不应期待它们自动增加已完成番茄数。
- 切换专注方案时，如果计时正在进行，新节奏会在后续阶段按界面规则生效，不会随意截断当前倒计时。
