# 手机端导航与常用操作

## 快速结论

手机端把主导航放在屏幕底部，核心功能与桌面端相同。部分面板会改为纵向排列或弹出式窗口，以适应较窄屏幕。

## 前置条件

- 使用手机浏览器打开时栈。
- 页面已经完整加载。

## 操作步骤

1. 在屏幕底部找到“专注”“任务”“时栈台”和“教程”。
2. 点击“专注”启动或控制番茄钟；计时器的重置、开始或暂停、跳过按钮位于计时器下方。
3. 点击“任务”创建项目，再进入项目添加任务或子任务。
4. 点击“时栈台”使用 AI 拆解；数据概览和日报周报位于该页面的“时栈舱”页签。
5. 点击页面上的“问小助手”打开客服；关闭按钮位于客服面板标题区域。

## 预期结果

- 底部导航在页面切换后仍可使用，并高亮当前模块。
- 表单和按钮按移动端宽度排列，不需要使用桌面顶部导航。

## 失败处理

1. 若底部导航被浏览器工具栏遮挡，先轻微滚动页面或隐藏浏览器工具栏，再操作。
2. 若弹出的输入面板被软键盘遮挡，收起键盘后继续，或滚动面板到目标按钮。
3. 若按钮文字没有完整显示，切换为竖屏并刷新页面；仍有问题时记录手机型号、浏览器和具体页面。
4. 不同版本页面布局可能变化。客服无法确认按钮位置时，应先询问用户当前页面名称和设备类型。
