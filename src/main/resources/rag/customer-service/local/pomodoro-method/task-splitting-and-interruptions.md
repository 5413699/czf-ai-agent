# 用番茄工作法拆解任务并处理中断

## 快速判断任务是否足够小

“写论文”是项目，不是本轮动作；“为实验设置章节列出五个小标题”才是可以开始的动作。好的番茄任务应该有动词、对象和可检查的结束标志。

## 前置条件

- 已选定一个大目标或项目。
- 知道当前一轮准备使用的大致专注时长。

## 拆解步骤

1. 写下最终目标以及怎样才算完成。
2. 列出到达目标必须产生的中间成果，例如提纲、代码、测试结果或复习卡片。
3. 将中间成果拆成可直接开始的动作，避免“学习一下”“继续处理”等模糊表述。
4. 为每个动作写完成标准，例如“得到可以运行的测试并记录失败输出”。
5. 估计需要几轮专注；明显跨越多轮的动作继续拆分。
6. 只选择下一项动作进入当前番茄，其余内容留在任务清单。

## 处理中断

1. **内部中断**：突然想到购物、消息或另一项任务时，快速记下一句话，然后回到当前动作。
2. **可延迟的外部中断**：告知对方预计可回复时间，记录事项，专注结束后处理。
3. **紧急外部中断**：立即停止计时并处理现实优先事项，之后重新开始一轮。
4. 每天复盘反复出现的中断，提前关闭通知、准备资料或调整工作环境。

## 预期结果

- 开始计时后无需继续决定“接下来做什么”。
- 中断得到记录，但不会自动夺走当前任务的注意力。
- 多轮记录逐渐提高对任务工作量的估计准确度。

## 失败处理

1. 若任务经常做不完，不代表用户失败；应优先检查任务粒度和估算，而不是无限延长工作时间。
2. 若工作本身需要随时响应他人，不应假装所有中断都能隔离，可改用更短周期或为响应工作单独安排时间块。
3. 若中断来自健康、安全或照护责任，应优先处理现实需求，不能让计时规则高于人身需要。
