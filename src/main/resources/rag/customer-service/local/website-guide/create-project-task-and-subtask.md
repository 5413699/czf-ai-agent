# 创建项目、任务和子任务

## 快速理解

项目像文件夹，任务像文件夹中的交付物，子任务是可以直接动手的小步骤。三层结构可以让每一颗番茄都知道自己在推进什么。

## 前置条件

- 已进入“任务”页面。

## 创建项目

1. 点击“新建项目”。
2. 填写唯一且容易辨认的项目名称。
3. 按需填写项目描述和偏好的专注方案。
4. 点击“创建项目”。

## 在项目中创建任务

1. 在项目列表中选择目标项目。
2. 保持“任务列表”页签处于选中状态。
3. 点击“添加任务”。
4. 填写任务名称、预计时间，并按需填写描述和以 `http://` 或 `https://` 开头的任务主页。
5. 点击“添加任务”。

## 在任务中创建子任务

1. 展开目标任务。
2. 点击“添加子任务”。
3. 填写子任务名称、预计时间，并按需填写描述和链接。
4. 点击“添加子任务”。

## 预期结果

- 项目出现在项目列表中。
- 任务出现在所选项目内，预计时间会按项目的专注节奏换算为番茄数量。
- 子任务出现在对应任务下，并可单独标记完成或关联专注。

## 失败处理

1. 若项目无法保存，确认名称不为空，并且没有同名项目。
2. 若任务或子任务链接报错，使用完整的 `http://` 或 `https://` 地址；不需要链接时可留空。
3. 若找不到刚创建的内容，检查“进行中”“已归档”“全部”等筛选条件。
4. 删除项目前先确认：项目内的任务、子任务和资料链接会一起删除；历史专注记录会保留，但会解除原有关联。
