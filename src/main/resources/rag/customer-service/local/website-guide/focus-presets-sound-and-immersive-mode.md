# 设置专注方案、背景声音和沉浸模式

## 前置条件

- 已进入“专注”页面。
- 上传自定义声音时，浏览器需要支持本地文件选择和浏览器数据库存储。

## 操作步骤

1. 在“本次节奏”选择内置方案，或点击新建方案按钮创建自己的节奏。
2. 编辑方案名称、专注时长、短休息和长休息时长，然后点击“保存并使用”。
3. 在声音区域选择背景音乐和环境音，并用音量滑块调整总音量、音乐音量、环境音音量与提示音量。
4. 如需使用自己的音频，点击“添加背景音乐”或“添加环境音”，从设备选择文件。
5. 如需减少页面干扰，点击“进入沉浸”。
6. 在沉浸模式中可切换主题、计时器样式、实体或透明背景；点击“全屏”可请求浏览器全屏显示。
7. 需要返回普通页面时点击“退出”。

## 预期结果

- 当前方案名称与时长显示为新设置。
- 计时运行时播放已选择的声景。
- 沉浸模式只保留计时相关界面，并可按选择改变显示风格。

## 失败处理

1. 若声音不播放，确认设备未静音、网页标签页未静音，并在页面中主动点击一次播放或开始按钮。
2. 若上传失败，尝试体积更小且浏览器支持的音频文件，并检查设备可用存储空间。
3. 若全屏没有打开，浏览器可能阻止了全屏请求；保持在网站页面内再次点击“全屏”。
4. 若自定义方案消失，检查是否清理过站点数据、使用了隐私模式或切换了浏览器。

## 重要边界

- 内置方案不能直接删除；自定义方案可以删除。
- 自定义音频保存在当前浏览器设备中，不会自动同步到其他设备。
