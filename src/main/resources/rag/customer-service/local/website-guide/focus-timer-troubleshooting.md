# 番茄计时无法开始或无法正常运行的排查方法

## 快速判断

先把问题分成三类：按钮不可用、倒计时不变化、只有声音不播放。三类问题的处理方式不同。

## 前置条件

- 网站页面能够打开。
- 用户能够进入“专注”页面。

## 排查步骤

1. 确认页面显示了计时器和“开始专注”按钮。
2. 若页面空白或控件缺失，刷新页面；仍无效时关闭该标签页后重新打开网站。
3. 若按钮可点击但倒计时不变化，先点击“重置”，再重新点击“开始专注”。
4. 若使用了自定义方案，检查专注、短休息和长休息时长是否为大于 0 的数值。
5. 若只有声音没有播放，检查系统音量、浏览器标签页静音状态和页面音量滑块。
6. 若刷新后反复异常，尝试在同一浏览器的普通窗口中打开，避免隐私模式或严格的存储限制。
7. 若仍无法恢复，记录浏览器名称、设备类型、问题发生步骤和页面提示，再联系项目作者。

## 预期结果

- 点击“开始专注”后，倒计时每秒变化，按钮显示“暂停一下”。

## 失败处理

- 不要通过反复清空全部数据来处理普通计时问题，因为清空操作不可撤销。
- 如需测试是否由本地数据引起，应先在“数据概览”导出备份，再考虑清理站点数据。
- 客服无法根据现有资料确认浏览器内部错误时，应明确说明无法确认，并请用户提供可复现步骤，不应猜测原因。
