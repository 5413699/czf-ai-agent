# 保存项目资料链接和导入 B 站选集

## 快速理解

项目资料夹用于保存网页入口，不会把网页原文上传到项目中。B 站选集导入则会把每一集转换成一个子任务，适合把长课程变成可以逐步完成的清单。

## 前置条件

- 已在“任务”页面创建并选中一个项目。
- 保存链接时，地址需以 `http://` 或 `https://` 开头。

## 保存项目资料链接

1. 在所选项目中切换到“项目资料”页签。
2. 点击添加链接按钮。
3. 填写标题、完整网址和用途说明。
4. 保存后，从项目资料夹点击标题可打开原网页。

## 导入 B 站选集

1. 在所选项目的“任务列表”中点击“导入选集”。
2. 填写作为主任务的课程名称，并按需填写描述和 B 站视频主页。
3. 在“选集文本”中逐行粘贴“标题 + 时长”，例如 `1. 课程介绍 12:30`。
4. 如需快速获得选集文本，可从导入窗口下载项目提供的选集复制脚本，并在 B 站视频页使用。
5. 点击“解析并创建任务”。

## 预期结果

- 项目资料夹显示新链接，但原网页或文件不会被复制到番茄自习室。
- B 站课程创建为一个主任务，每条有效选集记录创建为子任务，并根据时长填写预计分钟数。

## 失败处理

1. 若资料链接无法保存，确认地址包含 `http://` 或 `https://`。
2. 若选集没有被正确识别，确保每行同时包含标题和 `分:秒` 或 `时:分:秒` 格式的时长。
3. 若分集链接不正确，检查任务主页是否为有效的 B 站视频地址；非 B 站地址不会自动生成分集参数。
4. 辅助脚本只能用于复制用户当前可见的选集信息，不代表番茄自习室托管或同步 B 站内容。
