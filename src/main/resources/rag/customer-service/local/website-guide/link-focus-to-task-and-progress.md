# 将番茄专注关联到项目任务并累计进度

## 前置条件

- 已在“任务”页面创建项目，以及需要关联的任务或子任务。
- 已进入“专注”页面。

## 操作步骤

1. 在专注页的任务选择框中展开目标项目。
2. 选择项目、任务或更具体的子任务。
3. 确认计时器旁显示了对应名称；按需补充本轮一句话目标。
4. 点击“开始专注”，并让专注阶段完整结束。
5. 进入“番茄智舱”的“数据概览”，查看新增的专注记录。
6. 返回“任务”页面，查看任务或子任务累计的已完成番茄数。

## 预期结果

- 每个完整完成的专注阶段生成一条记录。
- 关联到子任务的记录同时计入所属主任务的进度统计。
- 未选择项目时，记录作为“自由专注”保存。

## 失败处理

1. 若没有累计进度，确认本轮是否完整结束，而不是重置或跳过。
2. 若记录关联错了，在“数据概览”的最近专注记录中点击编辑，重新选择项目、任务和子任务。
3. 若任务已经归档，可通过任务筛选查看或恢复；历史记录不会因为归档而消失。
4. 若项目或任务已删除，历史记录仍保留，但会显示为自由专注或解除部分归属。
