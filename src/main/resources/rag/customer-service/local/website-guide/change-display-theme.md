# 切换极夜、永昼和护眼主题

## 前置条件

- 网站页面已经正常加载。

## 操作步骤

1. 在页面顶部右侧找到由月亮、太阳和叶子图标组成的主题切换区域；宽屏时图标旁会显示主题名称。
2. 选择月亮图标对应的“极夜”、太阳图标对应的“永昼”或叶子图标对应的“护眼”。
3. 如在专注沉浸模式中需要不同外观，使用沉浸工具栏单独选择主题。

## 预期结果

- “极夜”显示深色界面，“永昼”显示明亮界面，“护眼”显示更柔和的绿色调界面。
- 普通页面主题选择保存在当前浏览器中，刷新后通常继续使用。
- 沉浸模式主题可以与普通页面主题分别设置。

## 失败处理

1. 若主题没有变化，刷新页面后重新选择。
2. 若刷新后恢复默认主题，确认浏览器没有禁用站点存储或使用隐私模式。
3. 主题偏好只保存在当前浏览器，不会自动同步到其他设备。
