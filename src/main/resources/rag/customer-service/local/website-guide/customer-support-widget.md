# 使用时栈小助手提问、重试和清空会话

## 前置条件

- 网站页面已经加载。
- 若使用真实客服接口，部署环境需要启用对应后端服务。

## 操作步骤

1. 点击页面上的“问小助手”。
2. 首次使用时可点击推荐问题，也可在输入框中输入功能或操作问题。
3. 按 Enter 或点击发送按钮提交；使用 Shift+Enter 可以在问题中换行。
4. 回答生成过程中，如不想继续等待，点击停止按钮。
5. 后端不可用或超时时，点击“重试原问题”。
6. 如需删除当前浏览器保存的客服会话，点击客服标题区域的清空按钮，再确认清空。

## 预期结果

- 回答以逐步生成的方式显示。
- 有经过批准的公开来源时，回答下方显示来源标题与公开链接。
- 当前资料没有可靠答案时，页面明确显示“当前资料中没有找到可靠答案”。

## 失败处理

1. 若提示无法连接，检查网络和客服后端是否可用，再重试原问题。
2. 若等待超过约 30 秒，前端会按超时处理并保留可重试入口。
3. 若回答与页面实际功能不一致，以当前页面为准，并向维护者反馈问题与发生版本。
4. 清空会话后无法从当前浏览器恢复该段客服聊天记录。

## 安全边界

- 前端不会直接访问知识库，也不应显示知识库 ID、向量、内部切片、服务端配置或供应商密钥。
- 来源链接只有在明确标记为公开时才应显示。
- 客服找不到可靠资料时必须说明无法确认，不能编造操作步骤。
