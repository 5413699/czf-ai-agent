# 时栈页面与功能导航

## 快速理解

可以把时栈理解成一张个人工作台：**任务页负责决定做什么，专注页负责真正开始，时栈台负责把大目标拆小，数据概览负责回看成果。**

## 适用范围

- 适用版本：时栈 Web 1.0.0。
- 桌面端和移动端均适用，入口位置会随屏幕宽度变化。

## 主要页面

1. **专注**：选择专注方案、关联项目或任务、填写本轮目标并启动计时。
2. **任务**：创建项目、任务和子任务，保存项目资料链接，查看归档内容。
3. **时栈台**：通过 AI 直接拆解明确目标；页面中的 Agent 梳理还依赖相应后端服务。
4. **教程**：查看第一次使用时建议完成的三个步骤。
5. **数据概览与日报周报**：位于“时栈舱”页签内，可查看、修正专注记录并管理本地备份。

## 如何进入目标页面

### 前置条件

- 网站已经在浏览器中正常打开。

### 操作步骤

1. 桌面端在页面顶部找到主导航；移动端在页面底部找到主导航。
2. 点击“专注”“任务”“时栈台”或“教程”。
3. 如需数据概览或日报周报，先进入“时栈台”，再选择“时栈舱”中的对应页签。

### 预期结果

- 页面标题与所选功能一致，当前导航项显示为选中状态。

### 失败处理

1. 若点击后页面没有变化，刷新网站后重试。
2. 若地址无法打开，确认部署服务仍在运行且网络可用。
3. 若只有 AI 功能提示离线，普通计时和本地任务功能仍可单独使用。
